# Design

## Context

인자 묶음은 설정에서 읽은 글의 목록이고, 런타임의 포크 인자와 추가 폴더 뒤에 그대로 붙는다. 동기는 proposal.md의 Why를 본다.

## Goals / Non-Goals

**Goals:**

- 묶음의 인자에 스레드의 이름을 넣을 수 있게 한다.

**Non-Goals:**

- 원격 제어나 특정 런타임의 기능을 도구가 아는 것. 도구는 글자만 바꾼다.
- 저장소 이름, 경로 같은 다른 자리표시와 그 이스케이프.

## Decisions

### 글자를 그대로 바꾼다

각 인자에서 `{thread}`를 모두 스레드의 이름으로 바꾼다. 템플릿 문법(Go의 `text/template` 등)은 쓰지 않는다. 자리표시가 하나뿐이고, 템플릿 문법은 다른 중괄호 글을 오류로 만들거나 바꿀 수 있기 때문이다.

### 바꾼 결과는 인자 하나로 남는다

바꾼 뒤에도 인자를 쪼개지 않는다. 스레드 이름에는 빈칸이 들어갈 수 없으므로 인자의 수는 묶음과 같다. 설정에서 읽은 목록은 고치지 않고 새 목록을 만든다.

## Risks / Trade-offs

- [인자에 `{thread}`라는 글자 자체를 넘길 수 없다] → 쓰임이 없어 받아들인다. 필요해지면 이스케이프를 따로 정한다.
